# QQURZ Chess v1.9.1 — Instant Clock Slap

- The physical tournament clock is now the only human slap control in local 2D and premium 3D play; the extra below-board slap button was removed.
- Clock input fires on pointer-down for faster touch response on phones and desktop pointers.
- The rocker hit zones are larger for rapid play, while the visual clock remains compact.
- The rocker animation was shortened to 82 ms for a snappier physical response.
- In local 2D play the 3D clock sits tighter beside the board and uses a compact top-down camera.
- In premium 3D play the clock is smaller, stays beside the board, and the main camera is pulled back so the board and clock fit comfortably in one view.
- Generated TypeScript build-info/Vite output files are ignored so build artifacts do not clutter source control.
